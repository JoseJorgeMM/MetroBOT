# Investigación de tarifas de buses — 2026-10-12

## Resultado utilizable

**Ninguna de las ocho líneas investigadas tiene una tarifa completa numérica suficientemente verificada para incorporarla al catálogo exact-match.** No se ha cerrado la cadena código exacto de Google → operador → modalidad → tarifa plena vigente. Esto es un límite de la evidencia encontrada, no una afirmación de que dichas tarifas no existan.

En particular, **260-2 permanece sin tarifa y sin operador verificados para ese código exacto**. No equiparar 260-2 con 260, 260B, 260M, 260i, ni con un recorrido denominado Clínica o Córdoba. Tampoco se comprobó qué significan los sufijos -1 y -2 de Google.

Todos los valores monetarios mencionados como contexto son pesos colombianos (COP). No son filas habilitadas para cobrar. No se obtuvo una respuesta de Google con agencias, identificadores o tarifa de viaje durante esta investigación.

## Datos locales y alcance

Se leyó `public/rutas_integradas.json`: 125 registros. La búsqueda en `id` y `name` de las familias 260, 289, 250, 282, 254 y 309 no produjo coincidencias. Ese archivo no permite cerrar las correspondencias solicitadas. No se modificó ni compiló.

No se inspeccionaron credenciales, respuestas privadas o sesiones de Google; no se descargaron archivos privados; no se envió ningún mensaje a otra tarea. La única escritura de esta investigación es este informe. No se implementó engine, UI ni catálogo.

La fecha de rastreo del buscador no se tomó como fecha de publicación. Se descartaron para precios vigentes los tarifarios de 2018/2022/2025 y las tarifas de terceros. No se inspeccionó el texto completo de la resolución tarifaria distrital de 2026: la evidencia de tarifas urbanas se limita al comunicado S1.

Para cerrar una fila futura hace falta una fuente del operador o de Movilidad que vincule el código exacto con la tarifa completa, junto con la identificación de agencia que entrega Google. Mientras no exista, conservar el valor desconocido. Un total de viaje de Google, si está disponible con moneda explícita, sería evidencia independiente del total de ese itinerario; no demostraría la tarifa individual de cada bus.
